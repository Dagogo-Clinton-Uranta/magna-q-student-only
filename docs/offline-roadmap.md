# Offline roadmap

A later PWA may cache only the application shell and currently authorised question DTO. IndexedDB would hold encrypted-at-rest data where the platform provides reliable key protection, plus an idempotency-keyed answer queue. Sync must revalidate ownership, deadline and block status and surface conflicts explicitly. Correct answers and explanations must never be cached before tutor submission or timed completion. No complete offline mode is enabled in the initial release.
